El Orden es Inevitable

Visor de grafos (JSON) con simulación de ataque sencilla (eliminación aleatoria de nodos) para observar conectividad y fragmentación. Interfaz ligera, sin backend.

Ver redes Simular ataque

Concepto

La resiliencia de una red puede observarse midiendo cuánto se mantiene conectada cuando pierdes nodos o enlaces. Aquí lo hacemos de forma deliberadamente simple: eliminamos un porcentaje de nodos y medimos métricas básicas (componentes y componente gigante).

Formato JSON

Formato nuevo

{
  "nodes": [{"id":"n1","vector":[0,0,0], "coherent": true}],
  "edges": [{"source":"n1","target":"n2"}]
}

Formato legacy

{
  "data": {
    "nodes": [...],
    "connections": [{"source":"n1","target":"n2"}]
  }
}

Scripts

# generar ejemplo
.venv/bin/python3 scripts/data_generator.py --nodes 40 --output examples/example.json

# simular ataque
.venv/bin/python3 scripts/attack_simulator.py --input examples/example.json --output examples/example_after.json --attack-rate 0.30 --seed 42

Limitaciones (honestas)

  • Ataque simple: eliminación aleatoria de nodos (no hay estrategia adversaria).
  • No es un modelo científico completo; es una demo/visor para exploración visual.
  • JSON grandes pueden ser pesados: usa “Cargar archivo JSON”.
